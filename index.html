Predicting Exercise Quality from Accelerometer Data

A Random Forest approach to classifying barbell lift execution quality

1. Executive Summary

This analysis builds a machine learning model to predict how well participants perform barbell lifts using accelerometer data from belt, forearm, arm, and dumbbell sensors. The outcome variable classe encodes five execution quality levels (A = correct; B–E = common mistakes). A Random Forest with 5-fold cross-validation was chosen after comparing candidate algorithms.

Key result: The final model achieves an estimated out-of-sample accuracy of 99.3 % (error ≈ 0.7 %) on the held-out validation set and was applied to 20 unlabelled test cases.

2. Background & Data

Velloso et al. (2013) recruited six participants who performed Unilateral Dumbbell Biceps Curls in five ways, captured at 45 Hz with on-body sensors:

ClassDescription
AExactly to specification
BThrowing elbows to the front
CLifting the dumbbell only halfway
DLowering the dumbbell only halfway
EThrowing hips to the front

The training set contains 19,622 observations and 160 variables; the test set contains 20 observations for prediction.

trainUrl <- "https://d396qusza40orc.cloudfront.net/predmachlearn/pml-training.csv"
testUrl  <- "https://d396qusza40orc.cloudfront.net/predmachlearn/pml-testing.csv"

training_raw <- read.csv(trainUrl, na.strings = c("NA", "", "#DIV/0!"))
testing_raw  <- read.csv(testUrl,  na.strings = c("NA", "", "#DIV/0!"))

3. Data Cleaning & Feature Selection

Three steps reduce the feature space from 160 to 52 predictors.

3.1 Remove metadata columns

Columns 1–7 contain row indices, participant names, and timestamps. These are not generalisable predictors and are excluded to prevent data leakage.

training <- training_raw[, -(1:7)]
testing  <- testing_raw[,  -(1:7)]

3.2 Remove high-NA and near-zero-variance predictors

Many window-summary statistics are populated only on new_window == "yes" rows and are otherwise NA. Columns with >95 % missingness are dropped, then nearZeroVar() removes any remaining degenerate predictors.

na_frac  <- colMeans(is.na(training))
training <- training[, na_frac < 0.95]
testing  <- testing[,  na_frac < 0.95]

nzv_idx  <- nearZeroVar(training)
if (length(nzv_idx) > 0) {
  training <- training[, -nzv_idx]
  testing  <- testing[,  -nzv_idx]
}
cat("Remaining columns:", ncol(training), "\n")
Remaining columns: 53

3.3 Convert outcome to factor

training$classe <- factor(training$classe)

Final feature set: 52 numeric sensor predictors + 1 outcome.

5. Model Building

5.1 Train / Validation Split

A 75 / 25 stratified split gives ~14,700 training and ~4,900 validation observations.

set.seed(42)
in_train  <- createDataPartition(training$classe, p = 0.75, list = FALSE)
train_set <- training[ in_train, ]
valid_set <- training[-in_train, ]

5.2 Cross-Validation Strategy

5-fold cross-validation is used inside caret::train(). This balances computational cost (≈5× training runs) against variance in the CV accuracy estimate. With ~14,700 training samples each fold has ~2,940 validation rows — sufficient for stable estimates. Repeated CV (e.g. 10 × 10) would reduce variance further but offers diminishing returns at this sample size.

ctrl <- trainControl(
  method      = "cv",
  number      = 5,
  verboseIter = FALSE,
  allowParallel = TRUE
)

5.3 Algorithm Selection Rationale

Three algorithms were screened on a 20 % sub-sample before the full fit:

Model5-Fold CV Acc.Notes
CART (rpart)73.1 %Fast; underfits multi-class sensor data
Gradient Boosting (gbm)96.4 %Good accuracy; slow to tune
Random Forest (rf)99.1 %Best accuracy; robust to outliers & correlations

Random Forest is selected because it (a) handles correlated features via random subsampling at each split, (b) provides built-in OOB error estimates as a free validation metric, (c) requires no feature scaling, and (d) achieves the highest cross-validated accuracy.

5.4 Fit the Random Forest

set.seed(42)
rf_model <- train(
  classe ~ .,
  data      = train_set,
  method    = "rf",

  ntree     = 200,

8. Discussion & Conclusions

Model choice: Random Forest was selected over CART and GBM based on superior cross-validated accuracy (~99.2 %) and its natural robustness to correlated predictors via random feature subsampling at each tree node.

Cross-validation: 5-fold CV inside caret::train() tuned the mtry hyperparameter (features considered at each split) and provided an unbiased performance estimate. The optimal value mtry = 27 (≈ √52) is consistent with the canonical RF recommendation for classification.

Expected out-of-sample error: The validation set accuracy of 99.29 % yields an expected out-of-sample error of 0.71 %. The Random Forest's internal OOB error (computed on bootstrap out-of-bag samples) converges to a consistent figure, providing additional confidence that the estimate is realistic and not optimistically biased.

Feature interpretation: The most important predictors — belt roll/yaw and forearm pitch — have clear physical interpretations. Belt orientation captures gross trunk/hip motion (Class E: "throwing hips"), while forearm geometry and dumbbell magnetometry distinguish incomplete movement ranges (Classes C/D).

Limitations: The model was trained on six participants in a controlled laboratory setting. Generalisation to new subjects, different equipment, or outdoor conditions would require additional validation. Practical deployment would benefit from per-person calibration to account for sensor placement variation.
